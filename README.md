# Identities 恆等式

Interactive S2 maths lesson on the perfect square identities and the difference of two squares, in Traditional Chinese or English.

- **Learn 概念** – animated area models for (a + b)², (a − b)² and a² − b², box-method proof, which-identity guide, a number tester for misconceptions, common mistakes
- **Worked examples 例題** – 8 step-by-step examples on a chalkboard, incl. mental arithmetic (99², 1003 × 997) and ⭐⭐⭐ extensions
- **Practice 練習** – 30 questions in four levels (basics, coefficients, mental maths, extension); every wrong option explains the specific misconception

Single static page: open `index.html` in a browser, or deploy to Vercel / GitHub Pages.
